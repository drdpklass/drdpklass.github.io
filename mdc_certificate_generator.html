How to Use this Platform

  1. Registration: Choose category — Student / Volunteer / Organiser / Faculty Coordinator. Students fill Stream, Department, Year, Roll No. Faculty (Organiser or Coordinator) fill Designation (Professor, Associate Professor, Assistant Professor, Lecturer, etc.) instead of Roll/Stream/Year. Registration starts as Pending.
  2. Admin Approval: Admin must Approve registrations. Only approved students appear under Generate Certificates. Use Approve / Reject / Approve All Pending in Admin → All Registrations.
  3. Admin (IQAC / NSS / YRC Coordinator): Login from Admin Panel (password known only to authorised officers). Create/edit events, bulk import, edit or delete any registration, change event status to Completed, and generate all certificate types.
  4. Generate Certificates: Go to “Generate Certificates”. Select a Completed event → choose participants → select a template → Preview / Print, or use Bulk Export: Multi-page PDF, ZIP of individual PDFs, ZIP of PNG images, or CSV participant list.
  5. Programme types: NSS, YRC, Cultural, Sports, Academic, Other. Admin creates events; students register.
  6. Every certificate includes MDC + Vikram Dev University + Odisha logos. NSS shows NSS logo; YRC shows YRC logo; others use MDC as programme logo.
  7. Signatures: NSS / YRC Coordinator (for NSS/YRC) or IQAC Coordinator (Cultural / Sports / Academic / Other) + Principal.
  8. Connect Google Sheets via Apps Script (see MDC_Certificate_AppsScript.gs) under Admin → Cloud Sync.
  9. Data is stored in browser localStorage and can sync to your Google Spreadsheet via Apps Script (Admin → Google Sheets Cloud Sync).
Note: This is a client-side application. For multi-device sharing, export JSON and import on another computer, or host this HTML on a shared drive / college server.
